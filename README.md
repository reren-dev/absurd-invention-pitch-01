Entry for make.fun's [One-Sentence Absurd Invention Pitch](https://make.fun/bounty/u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a) bounty ($2.50 in USDC).

## The pitch

> A phone charger that retracts its cable like a startled animal every time you yank it, so the cord never frays and you never have to buy another one.

## How it works

`main.py` (Python 3.13, stdlib only, no network, no wall clock) writes the
one-sentence pitch to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The program validates
the pitch against the competition gate first: 1–220 characters, exactly one
sentence, not only whitespace. Two runs produce byte-identical output.
